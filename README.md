Development Guidelines

The bot is developed based on the My First Bot tutorial.

How to Run

Ensure the Robocode Tank Royale server is running.
Place the compiled bot files in the server’s bots directory.
Start a battle via the Robocode Tank Royale GUI or CLI, including TeamBotX.
Observe the bot’s performance and tweak the code as needed.

Judging Criteria
Our bot aims to excel in the following areas:

Functionality: Runs smoothly and participates in battles without issues.
Creativity & Strategy: Implements unique tactics for movement, targeting, and energy management.
